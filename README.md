# Docker Setup

This project is set up with Docker to run the frontend, database, pgAdmin, and Storybook.

## Steps to Set Up

### 1 Install Docker

### 2 Create Required Files
- Create a Dockerfile for the frontend.
- Create a Dockerfile for the PostgreSQL database.
- Create a Dockerfile for pgAdmin.
- Create a Dockerfile for Storybook.
- Create an Nginx configuration file to serve the frontend.
- Create an SQL file to define database tables and insert sample data.
- Create a docker-compose.yml file to define and manage the containers.

### 3 Build and Run the Containers
Run a command to build and start all services.

### 4 Access the Services
- Open the frontend in a browser http://localhost:3000
- Connect to the database using the provided credentials.
- Log in to pgAdmin to manage the database.
- Access Storybook to view UI components.

Now you’re all set!
